Your chat history is stored on your own computer. To generate replies, your messages and attachments are sent over the internet, so you need to be online to chat.

## ❓ FAQ

**Is it free?**
Yes. Download it and use it.

**Does it work on Mac or Linux?**
Not yet. Right now Aether is available for Windows 10 and 11.

**Why does Windows show a warning when I install it?**
The app isn't signed with a paid certificate, which Windows flags for any new app. Click **More info**, then **Run anyway**.

**My antivirus flagged the installer.**
Unsigned apps sometimes trigger false alarms. If you're unsure, scan the file before you run it, or skip it.

**A file I attached wasn't understood.**
Check the list of supported files above. Very long documents are shortened, and only the first 12 minutes of an audio or video file are transcribed.

**How do I uninstall it?**
Open Windows **Settings → Apps → Installed apps**, find **Aether AI**, and choose **Uninstall**.
